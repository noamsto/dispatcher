usage: crew roster-render --crew ID [--pane %N] [--no-open] [--once | --detach]
                          [--interval S] [--quiet S] [--legend full|counts|none]
       crew roster-render --map --crew ID --px WxH --out FILE [--select BRANCH]
                                 [--select-repo LABEL]

Draw the crew's roster diagram from the bus and its live role panes, and publish
it to the aeye carousel beside the recorded dispatcher pane.

  --crew       Crew id (required). One renderer per repo bus: a crew spanning
               several repos gets one diagram per repo, named by the owner
  --pane       Dispatcher pane to publish beside
  --no-open    Render and record without opening the carousel
  --once       Render one frame and exit
  --detach     Record the pane, start the daemon detached, return
  --interval   Redraw interval (default 2)
  --quiet      Exit after S seconds with no working/blocked/dispatched worker
               and no outstanding hold (default 1800; 0 exits as soon as the
               crew drains)
  --legend     How much legend the diagram draws (default counts):
                 full    every key and the budget strip under the diagram
                 counts  one row of state counts; the full key goes to
                         <stem>.legend.svg in the roster file's directory,
                         written only when its content changes
                 none    no legend
               <stem> is the roster file's name without .svg, so a viewer
               finds the key from the roster file's name. full and none write
               no legend file and remove a stale one an earlier run left
  --map        Draw once to a PNG without the legend and print the planets'
               places as one JSON line; reads the bus, writes nothing else,
               and refuses every flag above but --crew
  --px         The PNG's size, WxH, each side 64 to 4096
  --out        The PNG's path
  --select     Ring the planet of this branch
  --select-repo
               Ring only the planet of that repo's wedge (the label the map
               reports as repo); without it a branch is ringed in every repo

Usage errors exit 64, like `stream`; --once and --detach together are one.

  crew roster-render --crew <crew-id> --pane %N --detach
