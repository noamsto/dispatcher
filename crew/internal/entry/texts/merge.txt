usage: crew merge <N> [--dry-run] [--allow-no-ci] [--no-ledger] [--crew ID]

Squash-merge PR <N> only when it is safe to. The first failed check refuses
with exit 1 and one line naming it:

  1. the PR is open, not a draft, and mergeable
  2. every check on the head commit finished green (none: needs --allow-no-ci)
  3. the base branch's tip has no failing check run
  4. the worker's newest pr_open ledger for this PR still validates

  <N>            Pull request number
  --dry-run      Run the checks and print each result; do not merge
  --allow-no-ci  Accept a head with no checks at all
  --no-ledger    Skip the ledger check (a PR no worker opened)
  --crew         Look for the ledger in this crew's rows only

The merge is pinned to the head that was checked (--match-head-commit), so a
late push is refused rather than merged unreviewed. Nothing is posted.

  crew merge 123 --dry-run
