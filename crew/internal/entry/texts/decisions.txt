usage: crew decisions [--json] [--since <ms|duration>]

List the decisions announced by this host's dispatcher and by peer hosts,
oldest first. One line per decision:

  <RFC3339 UTC>  <origin>  <body>

origin is "local" for this host and the peer's host name otherwise. Hidden
code points are shown as \u{XXXX} and control characters, newlines included,
as "?", so one decision is always one line.

  --json            [{"ts","origin","crew_id","body"}], [] when there are none
  --since <ms|dur>  only decisions at or after an integer ms timestamp, or
                    within a Go duration (24h); anything else exits 2

  crew decisions --since 24h
