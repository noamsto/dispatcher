usage: crew dash [--crew <id>] [--narrow | --once | --json [--view <name> [--watch] [--keeps]]]

Terminal dashboard over the crew bus: Overview (attention strip), roster,
budget, holds, retro, and Fleet (machine-wide attention, crews, capacity,
holds, hosts).

  --crew <id>    Scope the crew tabs to one crew (default: $CREW_ID, else the
                 crew whose dispatcher pane shares this tmux window; none →
                 unscoped)
  --narrow       Force the stacked narrow layout (for a side pane) at any width
  --once         Print one snapshot and exit instead of running the UI
  --json         Emit that snapshot as JSON
  --view <name>  With --json: print one view model (overview, roster, budget,
                 runs, settings, map, fleet)
  --watch        With --view: one JSON line per bus change, incl. relayed
                 remote-worker batches and peer syncs. Fleet also emits one
                 every 30 s as a fallback refresh, so a line is not always
                 a change.

  crew dash --once
