usage: crew remote-run --host H [--env K=V]... [--spec-file F] -- <argv>...

Run one command in this repo's clone on remote host H, over ssh, and print its
output. The host, its ssh destination and the clone's path come from the settings
`hosts` key (hosts.H.ssh, hosts.H.repos); nothing else names them. The command
is sent as one JSON request to `crew remote-exec` on the other side, which runs
only an allowlisted argv: dispatch, permission-check, or crew reply, nudge,
where, roster, relay, reap and dispatch-row.

Exits 2, before any ssh, for an unknown host, a clone that is not mapped, a bad
--env, or a caller that is not this crew's dispatcher (the sender check runs here,
before any ssh, since the remote cannot see this env or pane); otherwise with
ssh's own status (255: the ssh itself failed).

  --host       Host name, as in the settings
  --env        KEY=VALUE for the remote command; only CREW_ID, DISPATCH_TMUX_SESSION,
               DISPATCH_EMIT_ROW, DISPATCH_SESSION_ID and CREW_IDENTITY_AVOID
  --spec-file  A file whose text reaches the remote command as $DISPATCH_SPEC

  crew remote-run --host mini --env CREW_ID="$id" -- crew where lime
