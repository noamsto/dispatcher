usage: crew remote-run --host H [--crew-scope] [--env K=V]... [--spec-file F] [--migrate-dir D] -- <argv>...

Run one command in this repo's clone on remote host H (with --crew-scope, in the
remote user's home), over ssh, and print its output. The host, its ssh destination and the clone's path come from the settings
`hosts` key (hosts.H.ssh, hosts.H.repos); nothing else names them. The command
is sent as one JSON request to `crew remote-exec` on the other side, which runs
only an allowlisted argv: dispatch, permission-check, or crew reply, nudge,
where, roster, relay, reap, dispatch-row and peer-sync.

Exits 2, before any ssh, for an unknown host, a clone that is not mapped, a bad
--env, a crew-scope request with a spec or migrate file or a bad env, a bad or
missing --migrate-dir meta.json, or a caller that is not this
crew's dispatcher (the sender check runs here, before any ssh, since the remote
cannot see this env or pane); otherwise with ssh's own status (255: the ssh
itself failed).

  --host         Host name, as in the settings
  --crew-scope   Send a crew-scope request: only `crew relay`, `crew dispatch-row`,
                 `crew reply`, `crew nudge` or `crew where` with `--crew <CREW_ID>`,
                 for a visiting crew on H; env must be
                 exactly CREW_ID and DISPATCH_ORIGIN_HOST, with no --spec-file
                 or --migrate-dir; needs no git checkout here. reply, nudge and
                 where take `--crew <CREW_ID>`, then only reply's `--no-nudge` or
                 nudge's `--wait N`, then `--` and the positionals (reply's target
                 a `worker:` id)
  --env          KEY=VALUE for the remote command; only CREW_ID, DISPATCH_TMUX_SESSION,
                 DISPATCH_ORIGIN_HOST, DISPATCH_EMIT_ROW, DISPATCH_SESSION_ID and CREW_IDENTITY_AVOID,
                 and CREW_LAYOUT (2 only; makes the request v2, which a
                 pre-layout-2 remote refuses)
  --spec-file    A file whose text reaches the remote command as $DISPATCH_SPEC
  --migrate-dir  A `dispatch migrate` bundle: meta.json (required), patch and
                 transcript.jsonl (each optional). Only with `dispatch <tier> …`;
                 the remote checks it and hands it over as $DISPATCH_MIGRATE_DIR

  crew remote-run --host mini --env CREW_ID="$id" -- crew where lime
