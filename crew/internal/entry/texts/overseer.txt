usage: crew overseer msg [--host <h>] <repo> <crew> '<json>'
       crew overseer status --origin <host> [--since <ms>]
       crew overseer deliver --origin <host> -- <repo> <crew> '<json>'

Post the overseer's message to one crew's dispatcher, on that repo's bus. Only
the overseer session runs it: CREW_OVERSEER set to this host's name (uname -n
up to the first dot), no CREW_WORKER_ID or CREW_ROLE_ID, and no crew-stamped
pane above it; it is refused when tmux list-panes -a or the process ancestry
cannot be read. The row is from overseer:<host> to dispatcher:<crew>; crew msg
and crew status refuse an overseer: sender.

  --host   Post on another settings host instead: that host's own crew
           overseer deliver writes the row there; prints {"host","ts"}.
           <repo> is then named as that host's crew fleet names it
  <repo>   A repo as crew fleet names it (owner/name from its origin, else
           its checkout dir), or its git common dir; a name two buses share
           is refused — pass the common dir
  <crew>   A crew on that repo's bus (crew crews)
  <json>   One JSON object of at most 3500 bytes whose "kind" is ask,
           request, capacity or notice, with no control or invisible
           characters, escaped or not (compact one-line JSON, e.g. jq -c);
           its bus row must also fit 4096 bytes, where each " or \ is
           escaped, so counts twice

Runs from any directory. Exits 1 on any refusal, with nothing written.
With --host the far host has 30 s to answer. A failure after it was reached
(a lost connection, the timeout, a malformed answer) may leave the row posted
there, so check its bus before resending.

status and deliver are run by a federated overseer over ssh through crew
remote-exec; not for interactive use. status prints this host's fleet status
and the msgs to overseer:<origin> above --since (a millisecond ts) as one
JSON line; deliver posts a message relayed from overseer:<origin>, a host in
this host's settings, and prints its ts.

  crew overseer msg noamsto/dispatcher <crew-id> \
    '{"kind":"ask","detail":"worker violet blocked 45 min — handling it?"}'
