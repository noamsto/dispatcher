## Steps

Commands run from the worktree root in the devshell (`nix develop -c …`);
Go commands from `dash/`.

### G1 — foundation, `--once`, packaging (one subagent)

- [ ] **Step 1: capture contract fixtures before deleting bash** — with the
      bats fixture environment (copy `tests/crew-dash.bats` setup into a scratch
      script), run the bash `crew-dash --json` once → `dash/internal/once/testdata/snapshot.json`
      (with `now` = 1790000000 and paths normalised to `<BASE>`/`<USER>`/`<LOCKED>`);
      copy `tests/fixtures/crew-dash/once.golden` and `once-color.golden` →
      `dash/internal/once/testdata/`. Also capture, from the same env, each raw
      source stdout/stderr (`dispatch-config --show-origin`/`--layers`,
      `refresh-budget --report --json`, `crew retro/rate/crews`) into
      `dash/internal/data/testdata/` for the fake runner.
- [ ] **Step 2: module + data layer, test-first** — `go mod init`, add deps.
      `data` tests (fail first): fake-runner `Collect` → Snapshot whose JSON
      (`json.Marshal`, keys `now, settings, budget, runs, roster`) equals the
      captured `snapshot.json` modulo key order; each source failing alone → only
      its section's `error` set (`exit <rc>` when stderr empty); retro empty stdout
      → `{tags:[],unknown:[],rows:[]}`; retro JSON without `rows` → no panic,
      zero rows; settings leaf rule (object with exactly `origin`,`value` and
      string origin; a user object holding `value`/`origin` keys stays a branch);
      `editable`/`locked_only` as spec; `RecentEvents(path, "feat/x", 20)` over a
      testdata `events.jsonl` returns the last 20 events whose `from` is exactly `worker:feat/x` or starts with `worker:feat/x#` (a `worker:feat/x-y#s1` event is excluded)
      oldest-first and tolerates a torn last line. Pass-through sections (retro
      `tags`/`unknown`/row details, rate aggregates, roster workers, holds) are
      typed only for the fields the views read and otherwise kept as
      `json.RawMessage`/`map[string]any`, so the `--json` equality holds.
      Declare `CollectRoster(ctx, Runner, Config)` here too (the roster-only
      re-collect G3 needs), so G3 never edits `data/`. Then implement. `go test
./internal/data` → pass; `go vet ./...` clean.
- [ ] **Step 3: `once` renderer, test-first** — golden test: `once.Render(snapshot,
color=false)` == `once.golden`, `color=true` == `once-color.golden`; plus the
      backslash, large-value and CJK-untruncated cases as table tests. Port the
      bash jq renderer's rules exactly (badge column capped at 48, rate markers,
      crew grouping/order/last-3 notes, `reltime`, `usd`, `fmt1`, `clean`). Widths
      in `--once` are rune counts, as the bash/jq version (the golden is the
      arbiter). `go test ./internal/once` → pass.
- [ ] **Step 4: `main.go`** — `--once` → `once.Render` to stdout (colour:
      `CREW_DASH_COLOR=always|never|auto`, `NO_COLOR`, stdout TTY via
      `golang.org/x/term`), `--json` → indented Snapshot JSON, none → interactive
      if stdin and stdout are TTYs (for now calls a stub `ui.Run` that returns an
      error "not built yet" — replaced in G2), else `--once`; bad args → `usage:
crew dash [--once | --json]`, exit 2. A collector failure never exits non-zero.
- [ ] **Step 5: bats switch + delete bash** — `tests/crew-dash.bats`:
      `setup_file` uses `$CREW_DASH_BIN` when set, else runs `(cd dash && go build -o "$BATS_FILE_TMPDIR/crew-dash" .)`; every test exports `CREW_DASH_NOW=1790000000` for the Go side and KEEPS the `date` shim (`SHIM_NOW`), which `refresh-budget` and `crew roster` still read
      and the tests invoke that binary (same env, same fixtures, same goldens);
      delete tests 13–16 and `adapters/core/crew-dash.sh`. `bats
tests/crew-dash.bats` → 12/12 pass.
- [ ] **Step 6: flake** — `crew-dash = pkgs.buildGoModule { pname =
"crew-dash"; version = "0.1.0"; src = ./dash; vendorHash = "<from the first
failing build>"; ldflags = ["-s" "-w" "-X main.dispatchConfigBin=${dispatchConfig}/bin/dispatch-config"];
nativeBuildInputs = [pkgs.makeWrapper]; postInstall = "wrapProgram
$out/bin/crew-dash --prefix PATH : ${lib.makeBinPath [refresh-budget pkgs.git]}"; }`
      (`subPackages = ["."]`; `buildGoModule` names the binary `dash`, the last
      module-path element, so `postInstall` first runs `mv $out/bin/dash
      $out/bin/crew-dash`, then `wrapProgram`); `git add -N dash/` before any
      `nix build` (flakes see only indexed files); in
      `pre-commit.settings.hooks`, exclude `^dash/.*/testdata/` from
      `trim-trailing-whitespace` and `prettier` (padded `View()` goldens carry
      trailing spaces by design — the hook would fail `nix flake check` or
      strip them on commit); devshell `pkgs.go`; `treefmt.programs.gofmt.enable = true`. Go tests that need
      `git` get it via `nativeCheckInputs = [pkgs.git]` (or avoid git in tests).
      Commands: `nix build .#crew-dash .#crew .#default`; `nix flake check`;
      `bats tests/module.bats`; `./result/bin/crew dash --once` on this repo renders
      all four sections.

### G2 — TUI shell, Settings, Budget (one subagent, after G1)

- [ ] **Step 7: root model, keys, layout, test-first** — tests: `View()`
      returns `""` before a `WindowSizeMsg`; `1`–`4`/`tab`/`shift+tab` switch the
      active view; `?` toggles full help; `r` returns a collect `tea.Cmd` and a
      `snapshotMsg` replaces the snapshot and stamps `refreshed`; `q` quits;
      resize test (80×24 → 60×20 → 120×40, and 20×5): every frame has exactly
      `height` lines and every line's `ansi.StringWidth` ≤ `width`. Then
      implement `model.go` (root; `now func() time.Time` injected; views as
      sub-models behind a small interface `{Update(tea.Msg) (view, tea.Cmd);
View(w, h int) string; Keys() []key.Binding; Selection() data.Selection;
Capturing() bool}` — `Capturing` is true while a text input owns keys),
      `keys.go` (one `KeyMap`, help derived from it), `styles.go` (one place for
      every style; NO_COLOR → `lipgloss.SetColorProfile(termenv.Ascii)` in
      `ui.Run`), `layout.go` (measured chrome, inner sizes via frame sizes,
      clamps). `ui.Run(snapshot, collect func)` starts `tea.NewProgram(..., tea.WithAltScreen())`.
- [ ] **Step 8: Settings view, test-first** — tests: tree from rows (branch
      nodes per path prefix, all expanded initially); `enter`/`space`/`←`/`→`
      collapse/expand the cursor's branch, cursor clamps on collapse; `j`/`k`/`g`/`G`;
      `/` enters filter mode (`Capturing` true), typing `keyfile` leaves only
      `openrouter` › `keyFile` visible, `esc` clears; badges: under TrueColor the
      four origins render four different strings for the same text; the locked
      badge contains `🔒`; `Selection()` returns the cursor's `SettingRow`
      (Path/Origin/Editable). Golden frames 80×24 and 120×40 (ASCII profile)
      over the G1 snapshot: header layer paths, the long `keyFile` row truncated
      with `…`, badges right-aligned. `go test -update` generates; review them by
      reading, then commit.
- [ ] **Step 9: Budget view, test-first** — tests: one row per window with a
      `progress.ViewAs` gauge (width = remaining width after fixed columns,
      min 10, clamped), pace `+40`, `3d 12h`, verdict truncated at 80 cols and
      full in the `enter` detail; `unknown` engines; stale flag past 7200s; gauge
      style thresholds (85/95). Golden frames 80×24 and 120×40.

### G3 — Runs, Roster (one subagent, after G2)
